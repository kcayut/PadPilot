繁體中文

三步，開始使用 SidecarSwitch。

  1. 先安裝並開啟 BetterDisplay

    SidecarSwitch 需要 BetterDisplay App 持續執行。目前 SidecarSwitch 功能使用免費版即可，不需要 Pro 或有效試用資格。

    前往 BetterDisplay 官方下載說明

    BetterDisplay 的授權條款仍適用。

  2. 拖進 Applications，再開啟一次

    將磁碟映像檔中的 SidecarSwitch.app 拖到 Applications。複製完成後，從 Mac 的「應用程式」資料夾打開 SidecarSwitch。

  3. 首次開啟被阻擋時

    此預覽版尚未經 Developer ID 簽署與 Apple 公證。若出現無法驗證開發者或無法檢查惡意軟體的提示，先確認下載自 SidecarSwitch 的 GitHub Releases，且檔案未遭修改，再依下列方式開啟：

    系統設定→隱私權與安全性→強制打開→打開

    在「隱私權與安全性」向下捲動，找到 SidecarSwitch 的提示；再次確認時選「打開」。

    查看 Apple 的首次開啟說明

找不到「強制打開」？

先確認已從「應用程式」嘗試開啟 SidecarSwitch，再回到「隱私權與安全性」向下捲動。受管理的 Mac 可能無法使用此選項，請查閱 Apple 說明或聯絡管理員。

如果顯示「已損毀」或「會損壞你的電腦」

先停止安裝，勿直接套用上述例外開啟步驟。請從 SidecarSwitch 官方發行頁重新下載，並依 Apple 說明確認警告原因。

ENGLISH

Three steps to get started.

  1. Install and open BetterDisplay first

    SidecarSwitch requires the BetterDisplay app to stay running. Its free mode supports SidecarSwitch’s current features; Pro or an active trial is not required.

    Visit BetterDisplay’s official download guide

    BetterDisplay’s license terms still apply.

  2. Drag into Applications, then open once

    Drag SidecarSwitch.app from the disk image into Applications. After copying finishes, open SidecarSwitch from your Mac’s Applications folder.

  3. If macOS blocks the first launch

    This preview is not Developer ID signed or Apple notarized. If macOS cannot verify its developer or check it for malware, first confirm that your download came from SidecarSwitch’s GitHub Releases and has not been altered. Then follow this path:

    System Settings→Privacy & Security→Open Anyway→Open

    Scroll down in Privacy & Security to find the SidecarSwitch message. Choose Open when asked to confirm again.

    Read Apple’s first-launch instructions

Can’t find Open Anyway?

Try opening SidecarSwitch from Applications first, then return to Privacy & Security and scroll down. Managed Macs may restrict this option; check Apple’s guidance or contact your administrator.

If macOS says the app is damaged or will harm your computer

Stop installation instead of applying the exception above. Download a fresh copy from SidecarSwitch’s official release page and check Apple’s guidance for that warning.

日本語

3 ステップで使い始める。

  1. 先に BetterDisplay を入れて起動

    SidecarSwitch の利用中は BetterDisplay アプリを起動しておく必要があります。現在の SidecarSwitch の機能は無料モードで利用でき、Pro や有効な試用期間は必要ありません。

    BetterDisplay の公式ダウンロード案内

    BetterDisplay のライセンス条件は引き続き適用されます。

  2. Applications に入れ、一度開く

    ディスクイメージ内の SidecarSwitch.app を Applications にドラッグします。コピーが完了したら、Mac の「アプリケーション」フォルダから SidecarSwitch を開いてください。

  3. 初回起動がブロックされた場合

    このプレビュー版は Developer ID 署名・Apple 公証を取得していません。開発元や悪意あるソフトウェアの確認に関する警告が出たら、まず SidecarSwitch の GitHub Releases から入手し、変更されていないことを確認してから、次の順に操作します。

    システム設定→プライバシーとセキュリティ→このまま開く→開く

    「プライバシーとセキュリティ」を下にスクロールして SidecarSwitch の案内を探し、再度確認されたら「開く」を選びます。

    Apple の初回起動の手順を見る

「このまま開く」が見つからない場合

先に「アプリケーション」から SidecarSwitch を開く操作を試し、再び「プライバシーとセキュリティ」を下にスクロールしてください。管理対象の Mac では制限される場合があります。Apple の説明を確認するか、管理者にお問い合わせください。

「壊れている」または「コンピュータが破損する」と表示された場合

上記の例外を適用せず、インストールを中止してください。SidecarSwitch の公式リリースから再取得し、Apple の説明で警告の原因を確認してください。

# 開發與驗證紀錄

[使用者文件](../README.md)

這個資料夾保存「為什麼這樣改、如何驗證、哪些尚未驗證」，供維護者追溯設計與避免重複踩坑。開源專案可以保留這類工程筆記，但不是必備，也不是一般使用者的安裝前置步驟。

工作紀錄只使用繁體中文，不建立英文或日文副本；一般使用者文件仍維持三語。

- [無頭開機修復](2026-09-09-boot-review.md)：Generic Display 辨識與虛擬備援的取捨。
- [控制與診斷驗證](2026-09-10-controls-review.md)：共用控制入口、實機證據及 GUI 驗證邊界。
- [USB 喚醒與自動偵測初版](2026-09-10-usb-discovery.md)：事件整合、推定限制與當時預設值。
- [0.1.0 發布驗收](2026-09-11-release-readiness.md)：P0／P1、CI、已接受歷史路徑與待完成實機驗收。
- [Apple Silicon 封裝發行](2026-09-12-bundled-release.md)：內建／外部 Python、tag 自動發行、GUI 修正與本機驗證。
- [iPad 離線重試保護](2026-09-12-offline-ipad-retries.md)：停止無限重試與通知累積、恢復條件及驗證邊界。
- [全域連線快速鍵](2026-09-12-connection-hotkey.md)：自動／手動模式的單次要求、原生快捷鍵與驗證限制。
- [手動開機連線與按鍵錄製](2026-09-12-manual-boot-shortcut-recorder.md)：新安裝預設、開機單次要求、模式順序與三語介面驗證。

舊紀錄不隨功能變更改寫成「當時已完成」；需要修正時加註後續說明。對外使用方式以[安裝指南](../INSTALLATION.md)與[疑難排解](../TROUBLESHOOTING.md)為準。原始日誌、序號與私人路徑不要直接放進此處；先去識別，再保留必要證據。

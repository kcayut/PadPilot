# 手動模式開機連線與快速鍵錄製

本紀錄接續[全域連線快速鍵](2026-09-12-connection-hotkey.md)。先前的快捷鍵選單介面與驗證限制屬於當時證據；本次改動與驗證另列於此。

## 完成項目

- 新設定預設 `manual_only`，新增預設啟用的 `connect_on_boot`。既有設定檔若已指定模式，更新時維持原值；布林型別驗證與保存沿用既有設定交易。
- 設定與選單列都以手動、自動、偏好 iPad 排序。手動區新增開機無螢幕連線勾選項；自動區另列無法預先確定 Sidecar 可連線、系統可能頻繁警告的說明。
- 背景服務利用 macOS 開機識別記錄消耗過的啟動機會。同次開機重啟服務、取消勾選再勾回，不會重新取得機會。無法確認或安全保存記錄時不發起開機要求，保留手動連線能力。
- 開機要求共用原有探索迴圈，最初 30 秒內等待查詢完整且有可識別目標；實體螢幕存在、模式改變、停用選項、已有手動覆寫／連線轉換或逾時即結束。USB 喚醒可延長原本探索，但不延長這個期限。送出前再次確認無實體螢幕與手動模式，避免兩次觀測間的螢幕插入造成多餘連線。
- 連線沿用共用的一輪要求與原有最多 3 次、間隔 3 秒；之後斷線或 USB／iPad 重現不會在手動模式自動重連。這不是裝置已解鎖或必定可連線的證明；需要登入工作階段及已啟用登入自動啟動，無法在登入前執行。
- 快速鍵改用原生聚焦按鈕錄製，點選後按組合再儲存。支援常用實體按鍵、方向／導覽鍵與 F1–F20，仍須包含 Control 或 Command。錄製時暫停原有全域快速鍵，Esc、焦點／視窗切換可取消；不增加事件監聽權限或套件。開始錄製時保留設定版本，避免背景更新覆蓋新設定。
- 快速鍵與開機選項的保存都經由既有 CLI／IPC，不觸發硬體掃描或連線。

## 驗證

- `python3 scripts/check_release.py --gui` 通過：230 項測試、原生版面與三語、腳本語法、plist、版本、差異及既有隱私檢查。工作樹與未接受歷史掃描結果皆為 0，原有接受紀錄為 6。
- 新增的開機測試覆蓋設定預設、既有模式保留、設定交易不掃描、同次開機不重試、未知查詢等待、最多三次、後續 USB 不重連、期限與實體螢幕插入競態。
- 原生快速鍵測試覆蓋註冊衝突、重複按下、錄製暫停、拒絕單一字母、功能鍵組合、Esc 與焦點取消恢復。
- 補上錄製期間背景版本更新的保護後，再跑 `python3 scripts/check_gui_languages.py`：三語共 21 個頁面於 840px 全部通過，包含錄製草稿版本、開機勾選與共用交易斷言。
- 另外以隔離資料渲染真正的原生設定視窗，人工檢查三語畫面：模式順序、開機勾選、獨立警告與錄製按鈕皆可見，文字正常換行。預覽未操作使用者的裝置或設定。
- 已透過既有安裝器更新本機 App 並重啟：安裝檔與建置檔雜湊一致，原始設定檔內容未變，使用者既有手動模式與快速鍵保留；新選項有效值為 true。確認只有一個背景服務與一個已安裝選單 App，開機記錄與目前開機識別相符。這只能證明本次啟動路徑，不能代替重新開機測試。
- 軟體驗證不等於實機冷開機驗收；尚未重開電腦驗證無實體螢幕、USB／無線 iPad 真正連線。macOS Sidecar 本身的失敗對話框仍可能出現。

## 後續調整：三輪開機探索與解鎖說明

- 使用者確認「三輪」為每輪最多 30 秒、合計最多 90 秒。開機探索沿用原本約 2 秒掃描間隔，跨過第一、二輪後繼續；找到有效目標即提早提出一輪連線要求。90 秒內仍找不到就停止開機連線流程，USB 通知與同次開機服務重啟均不延長或重開這個機會。原本單輪連線的最多 3 次重試不增加。
- 全域快速鍵區新增三語說明：Mac 須已登入並解鎖，鎖定畫面時無法使用。同步更新三語一般使用者文件。
- 新增隔離時鐘測試，覆蓋第 2、3 輪找到目標、90 秒後才出現不連線，以及持續 USB 事件不能重開探索；既有 USB 迴圈測試改用隔離的開機機會，避免測試寫入使用者的開機紀錄。
- 完整測試為 231 項通過，三語共 21 個原生頁面檢查通過。本次整合檢查的版面項目初次遇到 `Missing native disclosure: paired`，同一輪後續三語檢查已通過相同頁面與操作；另行重跑版面檢查，7 個頁面全數通過，未放寬原有斷言。
- 三語原生預覽確認新增說明正常顯示與換行。已更新本機 App，安裝檔與建置檔一致，只有一個背景服務及選單 App，原始設定檔內容完整保留；尚未做實機重新開機驗收。

## ローカル安全性の修正概要

結果はこの P0-2 範囲で `fixed` です。プロジェクト全体の安全性認証ではありません。

- **信頼境界：** 他ユーザーが `/tmp/PadPilot` を事前作成できる可能性、ペアリング payload の UUID/シリアル、別 checkout の同名 LaunchAgent・CLI リンク・プロセス。
- **元の問題：** 状態権限が未制限、IPC payload 全記録、代替パスの読み取り・削除がリンクを追従、広範なプロセス終了。
- **共通修正：** `core/storage.py` で所有者・種類・リンクを検証し、`0700`/`0600` とアトミック書き込みを使用。GUI・メニュー・CLI・daemon が共有し、使用中 socket は上書きしない。
- **コマンド・起動管理：** 既知コマンド名だけを記録し、payload と未知の原文は記録しない。停止前に plist、読み込み済み job の出所・引数、Python とスクリプトを照合。導入・CLI・GUI は共通 autostart を使用。新規子プロセスの応答失敗時は終了・回収し、ログイン起動失敗時は以前の設定・実行状態の復元を試す。
- **独立した追加確認：** 代替状態の削除、メニュー非表示マーカー、子プロセス失敗の後処理、旧サービス停止後の復元に回帰テストを追加。
- **維持した動作：** JSON・legacy IPC、ペアリング、正常な状態操作、古い socket の置換、ログイン起動無効時の当該セッション動作、3 言語 UI。`--check` は書き込まず、Tk 不足でコアを止めない。
- **証拠：** `tests/test_release_safety.py`、`tests/test_install_check.py`、`tests/test_menu_pairing.py`、`tests/test_autostart.py`、`tests/test_native_app.py`、実 Tk のレイアウト・言語検証。
- **範囲外：** 同一アカウントでの任意コード実行や root は防御対象外。過去ログ・Git 履歴は書き換えず、全エラーの匿名化は保証しない。検査は限定された文字パターンで、完全な秘密情報検出ではない。

例外は `4c7642471fc316991ff8e0ab1ec678e347ce7ed4` と `fc53785b1d385d21aac6e8f9d93f4638b0f348ab` 内の指定ファイルと `private_path` 種類だけで、`scripts/check_release.py` に列挙します。報告の `accepted_history` に審査済み位置を残し、`tree` と `history` は未免除の一致を示します。新コミット、別ファイル、認証情報、現在のファイルには適用しません。本物の認証情報を見つけたら先に無効化・更新します。パスの許容はリポジトリ公開、タグ・Release 作成、実機検証完了を意味せず、`SECURITY.md` の非公開報告窓口も未有効です。

翻訳と精密な例外追加後、ローカル 167 テスト、実際の 3 言語 GUI 文書・診断リンクのクリック、840px と状態保持の検査が成功しました。tree=0、history=0、accepted_history=6 です。モニターなしの実機検証や、この変更の GitHub へのアップロード完了を意味するものではありません。

## 最終確認後の修正（2026-09-11）

導入前の実行状態を失う復元処理、主・代替設定の読み取り不一致、壊れた設定による自動制御の有効化、Sidecar 画面の誤識別、identifiers エラーの上書き、GUI の版照合漏れ、purge の代替設定漏れ、FileVault 診断判定、アンインストールスクリプトの検査漏れ、仮想画面名の表示を修正しました。PR テンプレートは既存のプライバシー検査を使い、導入・構成・トラブルシューティング文書を3言語で同期しました。長い設定パスは最小画面内で折り返します。

178 件の単体テストが ResourceWarning なしで成功し、840px のウィジェット・フォーカス・下書き・スクロール保持と3言語 GUI 検査も成功しました。導入失敗の復元は一時ユーザーディレクトリと仮サービスで、launchd・単独起動・停止済みを検証し、実際の導入やサービスは変更していません。両 Shell を個別検査し、plist・版・diff も成功しました。プライバシー結果は tree=0、history=0、accepted_history=6。変更は未配備・未プッシュです。

隔離したユーザーディレクトリで完全な `check_release.py --gui` が成功し、追跡中の Markdown 34 件に壊れたローカルリンクはありませんでした。GitHub の読み取り専用照会ではリポジトリは private のままで、非公開報告 API は 404 を返し、有効な報告窓口は確認できませんでした。

安全性方針から未有効化機能や未確認の連絡先への誘導を削除しました。公開可能な管理者メールまたは有効な非公開報告 URL が必要で、報告窓口と一般公開は未準備です。macOS 14 と実機受け入れは `unknown`、`stable_ready` は false のままです。
